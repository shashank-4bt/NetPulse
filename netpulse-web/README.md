# NetPulse web

Next.js App Router application for **NetPulse** (Internet Health Intelligence Platform).

This package currently contains the **design system and app shell only**. Diagnostic measurement, outage data, and live service status are not implemented and are not simulated.

## Scripts

From the repository root:

```bash
npm run dev
npm run lint
npm run typecheck
npm run test
npm run build
```

Or from this directory: `npm run dev`.

Open [http://localhost:3000](http://localhost:3000) for foundations, and `/design-system` for the component gallery.

Copy `.env.example` to `.env.local` for local overrides. Do not commit secrets.
